# fortyminsaway

Существующий интерактивный сайт трилогии «Сорок минут до дома», автор Joe. Восемь страниц, 57 глав / 62 раздела, 39 изображений галереи и 24 музыкальные композиции.

## Публикация из GitHub на Vercel

1. Загрузите содержимое **этой папки** в репозиторий GitHub `fortyminsaway`, сохраняя вложенные папки и точные имена файлов. Не загружайте проект как одну внешнюю папку или ZIP. В корне репозитория должны находиться `index.html`, `vercel.json`, `.gitignore`, `.vercelignore`, `assets/`, `books/`, `css/`, `js/`, `data/`.
2. В Vercel выберите **Add New → Project**, подключите GitHub и импортируйте этот репозиторий.
3. **Framework Preset: Other**, **Root Directory: корень репозитория**. Build Command и Install Command — пустые; Output Directory — `.`. Эти параметры уже записаны в `vercel.json`.
4. Запустите Deploy. Python, Flask, npm-зависимости, переменные окружения и серверные функции не требуются.
5. На выданном HTTPS-адресе проверьте главную, `/reader.html?v=volume-1&c=chapter-03`, галерею и запуск музыки кнопкой. Перезагрузите прямую ссылку на читалку.

Расширения `.html` сохранены намеренно: также без редиректов загружаются HTML-фрагменты глав в `books/`. Общего SPA-перенаправления на `index.html` нет. JSON, изображения и MP3 публикуются как реальные статические файлы.

`.vercelignore` допускает только страницы и папки сайта. `main.py` остаётся удобным **локальным** запуском; он не входит в публикацию. Тесты, отчёты, окружения и секреты также исключены из публикации. `.gitignore` не исключает авторские изображения, книги или разрешённые MP3.

Размер статической публикации — около 200 MiB, в основном музыка. Для этого проекта используйте запрошенный импорт из GitHub. Отдельный лимит загрузки исходников через Vercel CLI на Hobby составляет 100 MB; это ограничение CLI, а не результат проверки GitHub-деплоя. [Официальные ограничения](https://vercel.com/docs/limits#static-file-uploads).

**Музыка:** 25 октября 2026 года владелец проекта в этой сессии подтвердил права на все 24 песни. Поэтому исходные MP3 включены в состав сайта. Это запись подтверждения владельца, а не независимая юридическая проверка лицензий.

## Локальная проверка

Для обычного чтения: `python main.py` (Python 3.10+, без дополнительных библиотек).

Проверка именно статического состава публикации, без использования `main.py`: `python tests/check_static.py`. Проверки локального сервера: `python -m unittest discover -s tests -p test_main.py -v`.

Веб-часть использует только HTML/CSS/JavaScript/JSON. Внешние шрифты Google необязательны: предусмотрены резервные системные шрифты. Все изображения, музыка и тексты находятся в проекте.

Прогресс, темы, заметки и закладки хранятся в LocalStorage данного браузера и адреса сайта. Записи с localhost/IP автоматически не переходят на домен Vercel. Музыка запускается действием пользователя согласно правилам браузера.

Подробный отчёт, список недостающих материалов и границы проведённых проверок: [DEPLOYMENT_REPORT.md](DEPLOYMENT_REPORT.md).

Официальные параметры Vercel: [vercel.json](https://vercel.com/docs/project-configuration/vercel-json), [исключения публикации](https://vercel.com/docs/deployments/vercel-ignore).
